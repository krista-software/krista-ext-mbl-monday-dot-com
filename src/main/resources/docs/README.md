# MBL Monday Dot Com

Read, search, create and update monday.com board items from Krista agents, conversations and
workflows — without anyone opening monday.com.

The extension discovers each board's real groups and columns at run time, so "Owner", "Status" and
"Due Date" resolve to whatever columns that particular board actually uses. Nothing is hardcoded to
one board layout.
